# TRT Pro Trader v8.0 — Full Universe Breakout & Institutional Bot

Dual-engine institutional quantitative trading bot for Binance USDT-M Futures with real-time web dashboard and 146+ pairs screener.

## Features
- **Full Universe Scanner**: Real-time screening of 146+ liquid Binance USDT-M pairs.
- **Institutional Breakout Engine**: 4H Consolidation Squeeze + Volume Surge + Candle Displacement & Wick Rejection Filter.
- **SMC Pullback Reversal**: 1H Market Structure & HTF Confluence.
- **Safe Structural Stop-Loss**: 0.8% - 1.5% breathing room.
- **Dynamic 1% Account Risk**.
- **Real-Time Web Dashboard**: Port 8080 (or $PORT on cloud).

## Deployment (Render.com)
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python render_start.py`
